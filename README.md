# Електронний реєстр звернень (MVP)

Прототип веб-орієнтованої системи для реєстрації та управління зверненнями щодо благоустрою. Проєкт розроблено в рамках навчальної практики з урахуванням специфіки роботи компанії MagneticOne Municipal Technologies.

## Технологічний стек
* ОС: Arch Linux
* Вебсервер: Apache
* База даних: MariaDB (MySQL)
* Бекенд: PHP 8 (з використанням абстракції PDO)

## Структура проєкту
* /src — вихідний код веб-додатка (клієнтська форма, панель адміністратора, обробники запитів).
* /docs — проєктна документація (архітектурна модель C4, пояснювальні записки).

## Основний функціонал
1. Клієнтська частина: Подання звернення.
2. Адміністративна панель: Перегляд реєстру звернень.
3. Безпека: Захист від SQL-ін'єкцій за допомогою підготовлених запитів (Prepared Statements) та санітизація вводу для запобігання XSS.
