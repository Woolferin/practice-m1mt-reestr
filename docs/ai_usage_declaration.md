# Декларація про використання інструментів штучного інтелекту (AI Usage Declaration)

## 1. Загальні положення
Цей документ описує ступінь та характер використання великих мовних моделей (LLM) та інструментів на базі штучного інтелекту під час розробки системи «Електронний реєстр звернень». Усі згенеровані матеріали пройшли етап обов'язкового ручного рецензування, тестування та інтеграції розробником.

## 2. Напрямки використання AI-інструментів

### 2.1. Написання вихідного коду
* **Генерація базових структур (Boilerplate):** Використання ШІ для швидкого створення базової розмітки HTML/CSS клієнтських форм та таблиць адміністративної панелі.
* **Синтаксичні конструкції:** Допомога у формуванні підготовлених запитів (Prepared Statements) для об'єкта PDO у мові PHP.
* **JavaScript логіка:** Консультації щодо використання API відкритої бібліотеки Leaflet.js для інтерактивної роботи з картографічними тайлами.

### 2.2. Налаштування інфраструктури (DevOps)
* **Конфігурація серверного середовища:** Отримання довідкової інформації щодо налаштування віртуальних хостів веб-сервера Apache та ізоляції процесів у системі `systemd` на базі Arch Linux.
* **Діагностика:** Аналіз логів помилок сервера та синтаксичних помилок для прискорення процесу зневадження (Debugging).

### 2.3. Підготовка проєктної документації
* **Форматування та структурування:** Використання ШІ для трансформації технічних нотаток в офіційну проєктну документацію згідно з галузевими стандартами (Специфікація вимог, Керівництво користувача).
* **Генерація діаграм:** Допомога у написанні синтаксису мови Mermaid для візуалізації архітектурної C4-моделі, ER-діаграми бази даних та діаграми послідовності (Sequence Diagram).

## 3. Відповідальність та верифікація
Розробник підтверджує, що інструменти штучного інтелекту використовувалися виключно як допоміжний засіб (AI Pair Programming). Повна відповідальність за архітектурні рішення, безпеку даних (зокрема захист від SQL-ін'єкцій та XSS), а також працездатність кінцевого продукту лежить на авторі проєкту.
