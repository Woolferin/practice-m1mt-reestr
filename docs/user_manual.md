# Керівництво користувача та адміністратора

## 1. Інструкція для заявника (Громадянина)

Система призначена для швидкої реєстрації інцидентів, пов'язаних із благоустроєм, та передачі точних просторових координат до відповідальних служб.

### Порядок подання звернення:
1. **Відкриття форми:** Перейдіть на головну сторінку системи (за замовчуванням `http://m1mt-reestr.local`).
2. **Введення базових даних:** Заповніть обов'язкові текстові поля (ПІБ заявника, Орієнтовна адреса, Детальний опис проблеми).
3. **Вибір категорії:** Оберіть відповідний тип проблеми з випадаючого списку (наприклад, "Ями на дорогах" або "Проблеми з освітленням").
4. **Просторова прив'язка (Карта):** 
   * Знайдіть місце інциденту на інтерактивній карті. Для зручності використовуйте функції масштабування (+ / -).
   * Клікніть лівою кнопкою миші на точне місце проблеми. 
   * На карті з'явиться маркер, а під нею відобразяться зафіксовані координати. У разі помилки просто клікніть в інше місце — маркер переміститься автоматично.
5. **Відправка:** Натисніть кнопку "Відправити звернення". При успішному збереженні система видасть підтверджувальне повідомлення зеленим кольором.

## 2. Інструкція для Адміністратора

Панель адміністратора призначена для моніторингу нових звернень та управління їхнім життєвим циклом (статусами виконання).

### Порядок обробки реєстру:
1. **Доступ до панелі:** Перейдіть за адресою `/admin.php` у браузері.
2. **Перегляд реєстру:** Усі звернення відображаються у вигляді зведеної таблиці. Найновіші записи знаходяться у верхній частині таблиці.
3. **Робота з геоданими:** 
   * У колонці "Локація на карті" міститься посилання "Показати на карті".
   * При натисканні на нього відкриється нова вкладка із сервісом OpenStreetMap, де локація проблеми буде позначена маркером у центрі екрана.
4. **Зміна статусу звернення:** 
   * У колонці "Статус звернення" відображається поточний стан (кольоровий бейдж).
   * Для переведення заявки на наступний етап достатньо обрати нове значення ("В роботі" або "Вирішено") з випадаючого списку нижче.
   * Система автоматично збереже зміни та оновить сторінку одразу після вибору статусу. Додаткових кнопок збереження натискати не потрібно.
