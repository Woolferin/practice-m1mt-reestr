# Керівництво користувача та адміністратора

## 1. Інструкція для заявника (Громадянина)

Система призначена для швидкої реєстрації інцидентів, пов'язаних із благоустроєм, та передачі їх до відповідальних служб.

### Порядок подання звернення:
1. **Відкриття форми:** Перейдіть на головну сторінку системи (за замовчуванням `http://m1mt-reestr.local`).
2. **Введення базових даних:** Заповніть обов'язкові текстові поля (ПІБ заявника, Орієнтовна адреса, Детальний опис проблеми).
3. **Вибір категорії:** Оберіть відповідний тип проблеми з випадаючого списку (наприклад, "Ями на дорогах" або "Проблеми з освітленням").
4. **Відправка:** Натисніть кнопку "Відправити звернення". При успішному збереженні система видасть підтверджувальне повідомлення зеленим кольором.

---

## 2. Інструкція для Адміністратора

Панель адміністратора призначена для моніторингу нових звернень.

### Порядок обробки реєстру:
1. **Доступ до панелі:** Перейдіть за адресою `/admin.php` у браузері.
2. **Перегляд реєстру:** Усі звернення відображаються у вигляді зведеної таблиці. Найновіші записи знаходяться у верхній частині таблиці.
